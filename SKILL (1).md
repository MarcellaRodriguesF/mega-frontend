# Hub Mega Frontend
- Stack conhecida: Next.js App Router, React, TypeScript, TanStack Query, React Hook Form, Zod e CSS Modules. Confirme versões e padrões reais.
- Preserve a arquitetura e organização já existentes; não reorganize por preferência pessoal.
- Procure componentes equivalentes antes de criar novos.
- Reutilize hooks, serviços, contextos, componentes e utilitários existentes.
- Respeite limites Server/Client Components; use `use client` somente quando necessário.
- Use TanStack Query, React Hook Form e Zod conforme convenções existentes.
- Use CSS Modules e tokens existentes. Não introduza Tailwind, styled-components ou outra biblioteca sem autorização.
- Preserve padrões de tabelas, filtros, paginação, formulários, drawers, modais e navegação.
- Garanta labels, validações, feedback e acessibilidade.
- Trate loading, erro, vazio, sucesso e ações desabilitadas.
- Verifique responsividade, especialmente tabelas, formulários e drawers.
- Não considere controle visual como autorização: a API deve validar permissões.
